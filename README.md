### Lab Class 5 - Smart Banking System
A comprehensive C# application demonstrating core OOP concepts:
- **Encapsulation**: Private fields with public properties
- **Access Modifiers**: public, private, protected
- **Constructors**: Default, parameterized, copy, static, and constructor chaining
- **Inheritance**: Single, hierarchical, and multilevel
- **Polymorphism**: Runtime (virtual/override) and compile-time (method overloading)
- **Method Hiding**: Using `new` keyword
- **Sealed Methods**: Preventing further overriding
- **Structs & Enums**: Value types and named constants
- **Arrays**: Single-dimensional, multi-dimensional, and jagged arrays
- **Parameter Modifiers**: ref, out, and params

## 🚀 Getting Started

### Prerequisites
- Visual Studio 2019 or later
- .NET Framework 4.7.2+ or .NET 8.0+ (depending on project)

### Running the Projects

1. Clone the repository:
```bash
git clone <repository-url>
cd /workspace
```

2. Open any `.sln` file in Visual Studio

3. Build and run the solution
